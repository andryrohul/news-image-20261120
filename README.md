"The World in One Day" — a one-page newspaper front page summing up Friday 20 November 2026 in 26 date-checked stories across 8 regions: the Trump–Xi–Putin peace declaration in Shenzhen, the ICJ's genocide ruling on Myanmar, Anthropic's Nasdaq debut, Kyiv under missile fire, Houthi strikes on Riyadh, COP31's close, and markets sliding in a global AI sell-off.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to the output directory. `build_image.py` drew the image with Pillow on the build machine; it is kept here so the image can be rebuilt and checked.

## What is in the image

Lead: the Shenzhen trilateral summit and the ICJ ruling on Myanmar. Then eight region panels — North America, Latin America, Europe, Middle East, Africa, Asia–Pacific, South Asia, and Markets, Tech & Sport — with three stories each, every one an event of 20 November 2026 or first reported that day.
